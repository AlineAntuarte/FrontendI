# Introdução ao Desenvolvimento Web: Fundamentos de Frontend, HTML5 e CSS3 💻

Repositório destinado aos estudos da disciplina de **Programação Front-end I** no curso de **Análise e Desenvolvimento de Sistemas (ADS)** - IFSC São José.

## 📚 Tópicos Abrangidos e Habilidades Desenvolvidas

* **Estruturação com HTML5:** Domínio de tags semânticas (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`), criação de listas (`<ul>`, `<ol>`, `<dl>`) e construção de tabelas de dados complexas.
* **Estilização com CSS3:** Separação de responsabilidades com folhas de estilo externas, aplicação do Box Model (`margin`, `padding`), uso de variáveis globais (`:root`), e controle de posicionamento (`sticky`, `fixed`).
* **Seletores Avançados:** Uso de pseudo-classes como `:nth-child` para automação de estilos e `:hover` para interatividade em links e tabelas.
* **Multimídia e Navegação:** Gerenciamento de caminhos relativos para imagens e ícones, formatação de links âncora para navegação suave (*Smooth Scroll*), links externos, e protocolos de comunicação rápida (`mailto:` e `tel:`).

## 📂 Estrutura do Repositório

O projeto está organizado cronologicamente por aulas. Cada pasta contém os arquivos executáveis (`.html`, `.css`) e documentações de estudo elaboradas em Markdown (`.md`).

* [**aula01/**](./aula01/): Introdução à programação Web e configuração de ambiente.
* [**aula02/**](./aula02/): Elementos básicos de HTML, atributos e CSS Inline.
* [**aula03/**](./aula03/): Estruturação de Tabelas e Listas no HTML. *(Inclui notas teóricas adicionais)*.
* [**aula04/**](./aula04/): Aplicação de CSS externo, cores, estilização dinâmica de tabelas (efeito zebra) e correção de colapso de margens.
* [**aula05/**](./aula05/): Refatoração para HTML Semântico (substituição de `divs` genéricas) e entendimento prático dos modelos de renderização (Bloco vs. Linha).
* [**aula06/**](./aula06/): Organização com elementos genéricos, caracteres de escape, rotas de links e multimídia (inserção de ícones de habilidades e links do Lattes).

*(As pastas de aulas futuras já estão mapeadas na estrutura e serão documentadas conforme o andamento do semestre).*
