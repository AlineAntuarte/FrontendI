Minha Futura Carreira

Eu sou Aline Barbosa Antuarte, e não me contento em apenas usar a tecnologia; eu preciso entender como ela funciona por baixo do capô. Seja abrindo o meu Ideapad para manutenção ou desenvolver códigos, minha curiosidade é o que me move.

Atualmente, estou trilhando meu caminho no curso de ADS no IFSC, em São José. Lá, estou estudando Java e dominando ferramentas essenciais como o Git. Minha rotina é um equilíbrio entre resolver problemas complexos de lógica e redes e aproveitar momentos estratégicos de lazer — seja explorando cada detalhe de Red Dead Redemption 2 ou otimizando meu setup para rodar Valorant a 100Hz sem perda de FPS.

Para onde estou indo

Como estudante de Análise e Desenvolvimento de Sistemas com facilidade em hardware e infraestrutura, vejo meu futuro em caminhos sólidos e desafiadores: Desenvolvedora Java (Backend): Com a base que estou construindo no IFSC, me preparo para atuar em sistemas robustos. Java é a linguagem das grandes arquiteturas, e é onde pretendo consolidar minha carreira. Desenvolvedora Full Stack: Já estou explorando o Frontend (como na minha Aula 04), e essa visão completa me tornará uma profissional capaz de resolver problemas de ponta a ponta.

Meu Diferencial

O que me destaca é a minha autonomia. Eu não espero as soluções caírem do céu: se a internet oscila, abro o terminal para diagnosticar; se o VS Code apresenta um erro visual, dou um jeito de resetar o cache. No mercado, essa proatividade de resolver o problema é o que eu entrego de mais valioso.
